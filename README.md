## Программа

Код находится в каталоге [key_manager](key_manager): создание ключей AES и RSA,
хранение в зашифрованном файле (AES-256-GCM, ключ из пароля через scrypt),
экспорт и импорт ключей, консольное меню.

```bash
cd key_manager
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python main.py                   # запуск программы
pytest tests/ -v                 # тесты
```

Документация модулей (pydoc) — в каталоге [key_manager/docs](key_manager/docs).
