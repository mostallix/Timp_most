keymanager.storage		 index
keymanager/storage.py

Модуль зашифрованного хранилища ключей.
 
Содержимое хранилища сериализуется в JSON (а не pickle) и
шифруется паролем с помощью модуля crypto_utils (AES-256-GCM).
